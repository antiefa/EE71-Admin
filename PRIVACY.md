# Политика конфиденциальности / Privacy Policy

Дата вступления в силу / Effective date: 29 August 2026

## Русский

EE71 Панель работает локально в браузере пользователя.

- Расширение обращается только к HTTP-адресу мобильного роутера Alcatel EE71, который пользователь сам указывает на экране входа.
- Данные роутера — состояние, настройки, список устройств, сообщения, журнал, диагностика — читаются и записываются напрямую в роутер по локальной сети и никуда больше не передаются.
- Пароль от роутера нигде не сохраняется: он живёт только в памяти открытой вкладки панели и стирается из поля сразу после входа. Маркер сессии тоже хранится лишь в памяти вкладки.
- В хранилище браузера сохраняются только адрес роутера, имя пользователя, интервал автообновления и отметка о том, что предупреждение о риске принято.
- Резервная копия настроек и файл журнала сохраняются на компьютер пользователя обычной загрузкой браузера. Копию панель разбирает локально, чтобы показать её состав; никуда её содержимое не отправляется.
- Расширение не собирает аналитику, не использует рекламные идентификаторы, не продаёт данные и не отправляет данные роутера, историю браузера или персональную информацию разработчику либо сторонним сервисам.
- Разрешение на доступ к HTTP-адресу запрашивается только для указанного пользователем хоста. Его можно отозвать, удалив расширение или изменив разрешения в браузере.

Вопросы о конфиденциальности можно задать через [GitHub Issues](https://github.com/antiefa/EE71-Admin/issues).

## English

EE71 Admin operates locally in the user's browser.

- The extension connects only to the HTTP address of the Alcatel EE71 mobile router entered by the user on the sign-in screen.
- Router data — status, settings, client list, messages, log, diagnostics — is read from and written to the router directly over the local network and goes nowhere else.
- The router password is never stored: it lives only in the memory of the open panel tab and is cleared from the field right after sign-in. The session token is likewise kept in tab memory only.
- Browser storage holds only the router address, the user name, the auto-refresh interval, and a flag recording that the risk warning was accepted.
- A settings backup and the log file are saved to the user's computer through a normal browser download. Backups are parsed locally to display their contents; nothing from them is transmitted anywhere.
- The extension does not collect analytics, use advertising identifiers, sell data, or transmit router data, browsing history, or personal information to the developer or third-party services.
- HTTP host access is requested only for the host entered by the user. The permission can be revoked by removing the extension or changing its browser permissions.

Privacy questions can be submitted through [GitHub Issues](https://github.com/antiefa/EE71-Admin/issues).
